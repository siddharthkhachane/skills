# s-skills

Claude Code skills for working in unfamiliar codebases. Run `/s:s-help` to list them.

## Install (plugin)

    /plugin marketplace add siddharthkhachane/skills
    /plugin install s@s-skills

Skills are namespaced: `/s:s-explore`, `/s:s-known`, ...

## Install (short names)

Copy the folders from `s/skills/` into `~/.claude/skills/`. Skills then run as `/s-explore`.

`terse-style-CLAUDE.md` is an optional global style file (copy to `~/.claude/CLAUDE.md`).
